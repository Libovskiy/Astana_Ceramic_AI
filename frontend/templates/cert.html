🔒 Заводской сертификат

Ставится один раз на каждое устройство — телефон, ноутбук, компьютер в цеху. После этого сайт открывается по защищённому адресу без предупреждений, а на телефоне начинают работать уведомления и диктофон: без защищённого адреса браузер их просто не даёт.

Это сертификат нашего собственного сервера. Он действует только для сайта завода и ничего не меняет в остальном интернете.

⬇️ Скачать сертификат

Постоянный адрес сайта

https://acai.local:8443

Этот адрес не меняется, даже когда роутер выдаёт компьютеру новый IP. Наведите камеру телефона на код — откроется эта же страница.

Телефон на Android

  1. Нажмите «Скачать сертификат» выше.
  2. Откройте Настройки → Безопасность (или «Биометрия и безопасность») → Другие настройки безопасности → Шифрование и учётные данные → Установить сертификат → Сертификат ЦС.
    Проще: в поиске по настройкам наберите «сертификат».
  3. Нажмите «Всё равно установить» и выберите скачанный файл ACAI-Astana-Ceramic.crt.
  4. Откройте защищённый адрес (кнопка внизу) и войдите.
  5. Меню браузера → «Добавить на главный экран»: значок открывает сайт сразу, без набора адреса.

iPhone и iPad

  1. Откройте эту страницу в Safari (в других браузерах профиль не установится) и нажмите «Скачать сертификат» → «Разрешить».
  2. Настройки → Основные → VPN и управление устройством → профиль «ACAI Astana Ceramic» → Установить.
  3. Настройки → Основные → Об этом устройстве → Доверие сертификатам → включите переключатель «ACAI Astana Ceramic».
    Без этого шага iPhone файл поставит, но доверять не будет.
  4. Откройте защищённый адрес, затем «Поделиться» ⬆️ → «На экран Домой».
    Уведомления на iPhone приходят только если сайт открыт с этого значка (так устроена iOS с версии 16.4).

Компьютер и ноутбук на Windows

  1. Нажмите «Скачать сертификат» выше — файл ACAI-Astana-Ceramic.crt попадёт в «Загрузки».
  2. Дважды щёлкните по нему → Установить сертификат.
  3. Выберите «Локальный компьютер» (нужен пароль администратора) — тогда сертификат будет работать для всех, кто садится за этот компьютер. Если пароля нет, выберите «Текущий пользователь».
  4. «Поместить все сертификаты в следующее хранилище» → Обзор → Доверенные корневые центры сертификации → Далее → Готово → «Да» на предупреждение.
  5. Закройте браузер полностью и откройте защищённый адрес заново.
    Firefox хранит сертификаты отдельно: в нём Настройки → Приватность и защита → Сертификаты → Просмотр сертификатов → Центры сертификации → Импортировать → отметить «Доверять при идентификации веб-сайтов».

Mac (компьютер или ноутбук)

  1. Нажмите «Скачать сертификат» выше.
  2. Откройте Связку ключей (Keychain Access) → слева «Система» → перетащите в неё скачанный файл. Понадобится пароль от компьютера.
    На новых macOS: приложение «Связка ключей» ищется через Spotlight (⌘ + пробел).
  3. Найдите строку «ACAI Astana Ceramic», откройте двойным щелчком → раздел «Доверие» → «При использовании этого сертификата» → «Всегда доверять» → закройте окно и введите пароль.
  4. Откройте защищённый адрес заново.

Если сайт не открывается

  1. Устройство должно быть в той же сети завода (тот же Wi-Fi), не в мобильном интернете.
  2. Если acai.local не открывается — попробуйте адрес по цифрам: —.
    Имя acai.local понимают телефоны, Mac и почти все Android. Старая Windows иногда не понимает — там работают цифры.
  3. Сертификат ставится один раз. Если раньше он работал, а теперь нет — сообщите: возможно, сервер сменил адрес.

После входа: колокольчик 🔔 (или кнопка «Включить уведомления» в «Обращениях») → «Включить» → «Разрешить».
