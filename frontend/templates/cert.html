🔒 Заводской сертификат

Нужен один раз на каждом телефоне, чтобы работали уведомления на телефон и диктофон. После установки сайт открывается по защищённому адресу без предупреждений.

Это сертификат нашего сервера ACAI, он действует только для сайта завода.

⬇️ Скачать сертификат

Android

  1. Нажмите «Скачать сертификат» выше.
  2. Откройте Настройки → Безопасность (или «Биометрия и безопасность») → Другие настройки безопасности → Шифрование и учётные данные → Установить сертификат → Сертификат ЦС.
    Проще: в поиске настроек наберите «сертификат ЦС».
  3. Нажмите «Всё равно установить», выберите скачанный файл ACAI-Astana-Ceramic.crt.
  4. Откройте сайт по защищённому адресу (кнопка ниже).

iPhone

  1. Откройте эту страницу в Safari и нажмите «Скачать сертификат» → «Разрешить».
  2. Настройки → Основные → VPN и управление устройством → профиль «ACAI Astana Ceramic» → Установить.
  3. Настройки → Основные → Об этом устройстве → Доверие сертификатам → включите «ACAI Astana Ceramic».
  4. Откройте сайт по защищённому адресу, затем «Поделиться» ⬆️ → «На экран Домой». Уведомления на iPhone работают только из значка на экране (iOS 16.4+).
Открыть защищённый адрес →

После входа: колокольчик 🔔 (или кнопка «Включить уведомления» в «Обращениях») → «Включить» → «Разрешить».
